# Marketplace Transfer 0.4.0

Windows-программа для переноса товаров из Excel Ozon в черновики Авито с фотографиями, описаниями, ценами и характеристиками. Работает через расширение в обычном авторизованном Google Chrome. Поддерживает проверку дубликатов, очередь с паузой и восстановлением, настройку темпа и постоянную историю. Объявления сохраняются в черновиках; публикацию пользователь выполняет самостоятельно.

Добавлена постоянная история по сеансам с итогами, длительностью, снимками товаров и экспортом в Excel. Миграция схемы 2 → 3 предварительно создаёт резервную копию; товары, события, ID и ссылки сохраняются. Старые события показаны как восстановленные группы по дате/файлу: точные границы прежних запусков и их длительность не выдумываются.

Реализованы подписанные обновления GitHub Releases и отдельный процесс установки/отката. Репозиторий пока не задан; полноценная онлайн-установка настоящего релиза не проверена. Источник можно один раз указать в «Настройках», доверенный открытый ключ при этом не меняется. Публикация и ограничения: [docs/UPDATES.md](docs/UPDATES.md).

В «Настройках» доступны связанные поля «Карточек в час» и «Секунд на карточку»: пересчёт 3600 / значение, точность до 0,01 секунды. Ноль отключает плановое ограничение. Кнопка «Применить темп очереди» применяет настройку после текущей карточки. В адаптивном режиме это стартовое значение; границы регулируются отдельно. Заданный темп и фактическая скорость показываются отдельно. Уже сохранённые черновики не меняются.

Адаптивный темп включается в «Настройках»: после трёх подтверждённых сохранений цикл сокращается на 10 секунд, при временном сетевом сбое увеличивается на 25% (минимум на 5 секунд). Текущие настройки пользователя: старт — 100 секунд, границы — 45–100 секунд. Это целевой интервал между началами карточек; фактическое время зависит от сайта и загрузки фотографий. Три временных сбоя подряд, CAPTCHA, потеря подключения и явные ограничения сайта останавливают очередь. Ошибки данных темп не увеличивают. Обученный интервал сохраняется в SQLite; неизвестный результат записи не повторяется автоматически.

Настройка «Плановый темп» задаёт время между началами товаров, включая создание и проверку: 120 секунд ≈ 30 товаров/час. Время сверх работы карточки добавляется как ожидание с обратным отсчётом. Пауза и остановка действуют в этом ожидании; последняя карточка не вызывает лишнюю задержку.

Windows 10 x64, Python 3.11, PySide6, SQLite. Импорт XLSX/XLS/CSV Ozon и перенос в **черновики** Авито через расширение Manifest V3 и Native Messaging в обычном авторизованном Chrome.

Рабочая интеграция проверена на реальном аккаунте: программа сохранила и подтвердила 93 черновика с фотографиями. Из остальных позиций пользователь подтвердил 11 выполненными вручную и 13 уже существующими. Эти подтверждения сохраняются отдельно от проверки ID/фото программой и блокируют повторное создание. Полностью автоматическое создание всех 117 товаров без ручного участия не заявляется. Подробные результаты и ограничения — `outputs/РЕАЛЬНАЯ_ПРОВЕРКА.md`.

## Запуск и разработка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e '.[dev]'
python run.py
python -m pytest -q
node --test tests/extension.test.cjs
```

Для Native Messaging необходим отдельный собранный `MarketplaceTransferHost.exe`; при запуске исходников приложение ищет его в `outputs/MarketplaceTransfer`. Пароли, cookies и токены сайта приложение не читает.

## Сборка Windows

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

Результат — вся папка `outputs/MarketplaceTransfer`, а не один EXE. При наличии Inno Setup 6 (`ISCC.exe` в PATH или `work/tools/inno/ISCC.exe`) собирается `outputs/MarketplaceTransfer_Setup.exe`. Сборка выполняется на Windows; PyInstaller не является кросс-компилятором. Зафиксированные версии проверенной среды: `requirements-build.txt`.

## Модули

- `importing`, `domain`, `titles`: чтение, сопоставление колонок, проверка вариантов, названия Авито.
- `storage`, `history`, `history_schema`, `engine`, `service`: SQLite, история сеансов, последовательная очередь, сверка перед созданием, восстановление неизвестного результата.
- `bridge`, `native_host`, `registration`, `extension/`: локальный аутентифицированный транспорт и разрешённые операции Chrome.
- `inventory`, `navigation`, `drafts`, `photos`: полная инвентаризация, реальные формы, проверка сохранения и оригиналы фотографий.
- `app`: русский интерфейс и фоновые задачи Qt.
- `updating`, `update_ui`, `updater_entry`: проверка подписанных релизов, фоновая загрузка, отдельный процесс установки, контроль запуска и откат.

Данные хранятся отдельно от программы: `%LOCALAPPDATA%\MarketplaceTransferNew`. Обновление и переустановка не удаляют базу. Для переноса базы на другой компьютер используйте резервную копию, а расширение устанавливайте заново с разрешения пользователя.

Массовая очередь разрешается только после реальных тестовых черновиков, проверки фотографий и дублей, полной сверки текущего аккаунта и подтверждения категории. Неизвестные формы, неполная инвентаризация, CAPTCHA и потеря связи блокируют дальнейшие небезопасные действия. Автоматической публикации и платных операций нет.
